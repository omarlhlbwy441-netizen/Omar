
# نظام Nexus للتحكم المركزي

مرحباً بك في نظام **Nexus**، المنظومة البرمجية المتكاملة لإدارة التحديات، العائلات، والبث التلقائي، مع نظام صلاحيات ذكي يعتمد على رتب التنانين.

## المكونات البرمجية
- `main.py`: البوابة الأمنية واللوحة المركزية.
- `nexus_controller.py`: محرك إدارة المستخدمين ورتب التنانين.
- `challenges.py`: وحدة إدارة التحديات التنافسية.
- `families.py`: وحدة إدارة العائلات والأرصدة.
- `broadcast.py`: محرك الإشعارات والبث التلقائي.

## نظام التنانين (VIP Ranks)
يتمتع النظام بـ 8 مستويات من الصلاحيات:
1. تنين البرق | 2. تنين الجليد | 3. تنين النار | 4. تنين الأرض
5. تنين الرياح | 6. تنين الضوء | 7. تنين الظل | 8. التنين العظيم (Alpha)

## الاستخدام
للوصول إلى النظام، يجب التحقق بكلمة المرور الإدارية المحددة في النظام.
